Use VAT tools for EU VAT numbers and IBAN tools for bank account numbers. Report company name and validity from the API. Do not invent a registration.

## Setup

Connect the Veille MCP server at `https://mcp.veille.io/` (OAuth via https://app.veille.io). Never print API keys.
